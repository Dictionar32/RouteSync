# CLI Generators

## Install

```bash
npm install -g @routesync/cli
```

---

## Commands

### `routesync scan`

Scans Laravel `routes/api.php` and outputs a route manifest JSON.

```bash
npx routesync scan \
  --input routes/api.php \
  --output routesync.manifest.json \
  --baseURL http://localhost:8000/api
```

Output (`routesync.manifest.json`):

```json
{
  "version": "1.0.0",
  "baseURL": "http://localhost:8000/api",
  "generatedAt": "2025-01-01T00:00:00.000Z",
  "routes": [
    { "name": "login", "method": "POST", "path": "/login", "auth": false, "middleware": [] },
    { "name": "produk.index", "method": "GET", "path": "/produk", "auth": false, "middleware": [] },
    { "name": "orders.index", "method": "GET", "path": "/orders", "auth": true, "middleware": [] }
  ]
}
```

---

### `routesync generate`

Generates SDK files from an existing manifest.

```bash
npx routesync generate \
  --manifest routesync.manifest.json \
  --output src/api
```

Generates:

- `src/api/api.ts` — typed `defineApi()` client
- `src/api/types.ts` — TypeScript interfaces per resource
- `src/api/hooks.ts` — React Query hooks

---

### `routesync sync`

Scan + generate in one step (most common usage).

```bash
npx routesync sync \
  --input routes/api.php \
  --output src/api \
  --baseURL https://api.myapp.com/api
```

---

### `routesync watch`

Watch the routes file and re-sync automatically on every change.

```bash
npx routesync watch \
  --input routes/api.php \
  --output src/api
```

## Generated `api.ts` example

```ts
// Auto-generated by routesync
import { defineApi } from '@routesync/sdk'

export const api = defineApi({
  auth: {
    index: { method: 'POST', path: '/login' },
  },
  produk: {
    index:  { method: 'GET',  path: '/produk' },
    show:   { method: 'GET',  path: '/produk/{id}' },
    store:  { method: 'POST', path: '/admin/produk', auth: true },
  },
  orders: {
    index: { method: 'GET', path: '/orders', auth: true },
    show:  { method: 'GET', path: '/orders/{id}', auth: true },
  },
})

export default api
```

## Parsers

| Parser | Usage |
|---|---|
| `LaravelRouteParser` | Parses `routes/api.php` with `Route::` syntax |
| `PHPRouteParser` | Parses native PHP `$router->get()` patterns |
| `OpenApiParser` | Parses OpenAPI/Swagger JSON specs |
